# exchange · 物物等值换算

「一斤铜换多少斤铝才不亏？」——本工具给三样东西：**中值、区间、逐行核对表**。

    python scripts/exchange.py fetch
    python scripts/exchange.py convert --from 铜 --to 铝 --quantity 1 --unit 斤

## 为什么不是一个数字

单价是活的：期货有当日高低，现货有升贴水，实物有成色和加工费。给一个确定的「4.21 斤」是误导，
所以输出的是 **4.14 – 4.37 斤**，并逐行写明哪些必须人核对。

## 严谨性约定

| 约定 | 做法 |
|---|---|
| 不存单点 | 每个品种存 last / low / high，结论给区间 |
| 数据有出处 | 每行写来源和行情日期 |
| 数据有寿命 | 超 12 小时标「⚠ 请先 fetch」 |
| 分清价格性质 | 期货价 ≠ 现货价 ≠ 实物成交价 |
| 交易成本单列 | 加工费、运费、成色、税费全标「⚠ 未计入」 |
| 可手算复核 | 打印公式和代入值 |
| **双源交叉验证** | 新浪 + 东方财富，偏差 >2% 标「疑似数据错位」 |
| 不确定就说 | 标「❓ 请人工确认」 |

## 支持

单位：吨 / 公斤 / 斤 / 克
品种（元/吨连续合约）：铜、铝、锌、铅、镍、螺纹钢、玉米、豆粕

## 边界

- 期货价不是提货价（要加升贴水）
- 成色差异 10–30%（99.95% 铜 vs 废铜）
- 不含运费、加工费、税费
- 不构成交易建议
