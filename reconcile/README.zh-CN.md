# reconcile · 任意两个文件的对照

**两个文件进去，一张差异清单出来。** 不管它们是 Excel、CSV、Word、PPT 还是 Markdown。

它做的事只有四步：**抽取 → 对齐 → 比较 → 报告**。格式只是入口，比对照的永远是"带键的记录"。

```bash
python scripts/reconcile.py run 今日股价.xlsx 昨日股价.xlsx
python scripts/reconcile.py run 合同A.docx 合同B.docx
python scripts/reconcile.py run 物料A.xlsx 物料B.xlsx --key 物料号 --fields 单价,数量
python scripts/reconcile.py demo        # 造三组样例，跑给你看
```

## 三种对照，自动判断

| 两个文件 | 模式 | 怎么对 |
|---|---|---|
| 表格 + 表格（xlsx/csv） | record | 自动选主键列，其余列逐格比 |
| 文档 + 文档（docx/pptx/md/txt） | text | 段落按相似度对齐，再比数字和措辞 |
| 表格 + 文档 | 混合 | 抽键值对/文本，按名称对齐 |

## 为什么文档先比数字

两版合同只差一个字和 15,000 元，纯文本 diff 会把钱埋进噪音里。所以文档对照会**先抽出所有数字和日期**（`120,000`、`2026年12月31日`、`12 个月`），把这些变化标成高严重度，再把改写过的句子单独列出来。

实际跑出来的效果：

```
## 数值/金额不一致（3）
| 第二条…120000元含税 | 数字 / 日期 | 120000 | 135000 | 金额/日期/数量发生变化 |
| 第三条…2026年12月31日 | 数字 / 日期 | 2026年12月31日 | 2027年1月31日 | … |
| 第四条…12个月 | 数字 / 日期 | 12 | 24 | … |
## 仅右侧存在（1）
| 第五条…违约金 | 仅右侧存在 | — | 第五条 乙方逾期交付的，每日按合同总额的 0.5% 支付违约金。 | 右侧独有 |
```

## 比较规则

| 情况 | 怎么判 |
|---|---|
| 两边都是数字 | 换算到同一单位再比（`6.2kg` = `6200g`），按相对差 |
| 两边都是百分比 | 按**百分点**比（`1.2%` → `0.9%` 是 `-0.30pp`，不是 −25%） |
| 文本 vs 文本 | 相似度，低于 0.995 才算差异 |
| 文档里的数字/日期 | **高严重度**，不看措辞相似度 |
| 键只在一侧 | `仅左侧` / `仅右侧`，并把该行其他字段写进备注 |
| 键被改写 | 相似度 ≥82% 时模糊对齐，单独列表，方便你审 |

编号类键（`M-1004`、`600519`）**不会**做模糊匹配——`M-1004` 和 `M-1005` 是两个物料，不是一个的错别字。

## 输出

- `reconcile-out/<左>_vs_<右>.md`：报告
- `reconcile-diff.xlsx`：差异清单（可筛选，带严重度）+ 汇总页

## 边界（先说清楚）

- **图片、PDF、二进制**不支持，先转成 docx/xlsx/txt
- **语义等价**要同义词表：`营收` 和 `营业收入` 在程序眼里是两个键
- **自由文本**（没有结构的散文）会把每句话都报成差异——技术上正确，但没用
- **主键选错就全错**：报告里会写"左表主键列：xxx"，看着不对就用 `--key` 指定
- **顺序不算差异**：按主键匹配，文件重排不会被报出来（这正是它的价值）
