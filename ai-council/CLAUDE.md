@SKILL.md

When a request involves an irreversible or high-stakes decision, a contested
technical claim, security review, or the user asks for several models / a debate
/ 多模型 / 交叉验证: follow the council protocol in SKILL.md. Pick the lowest
rung of the ladder that can work (pair is usually enough), announce the call
count, and keep the dissent in the final answer.

Quick commands:

```bash
python scripts/council.py demo                        # offline shape check
python scripts/council.py run -c council.json --dry-run
python scripts/council.py run -c council.json
```

Never hide an unreachable seat, and never let the synthesiser invent a claim.
