# 任务框 · 填空模板

**每个 AI 收到的是同一份任务框。** 改一次，全部重贴。写不好任务框，后面四轮全白跑。

---

## 中文模板（复制，改尖括号）

```text
【要决策的问题】<一句话，能被证伪。不要写成"谈谈你对……的看法">
【交付物】<一句话，比如：一条决策 + 置信度 + 风险 + 下一步行动>
【约束】<团队人数/预算/时间/硬性要求，每条一行>
【不讨论】<明确排除的范围，每条一行>
【判断标准】<什么叫"这个决定做对了"？一句话>
```

坏例子 → 好例子：

- ❌ "如何看待 AI 多模型协作？" → ✅ "未来 3 个月，我是否应该花钱买 3 个 API 做多模型评审，还是继续用免费网页版手工搬运？"
- ❌ "帮我分析一下这个项目" → ✅ "这个仓库是否值得投入 20 小时做一个网页版演示？"

可证伪的意思是：**你能说出什么结果会让你改主意**。

---

## English template

```text
QUESTION: <one sentence, falsifiable>
DELIVERABLE: <one sentence: decision + confidence + risks + next action>
CONSTRAINTS: <team size / budget / deadline / hard requirements>
OUT OF SCOPE: <what is explicitly excluded>
SUCCESS CRITERIA: <what would make this decision correct?>
```

---

## 填好的例子（照这个粒度写）

```text
【要决策的问题】未来 3 个月，我是否应该为「多模型议事」买 3 个以上的 API，
放弃现在用网页版手工搬运的做法？

【交付物】一条决策 + 置信度 + 理由 + 未决分歧 + 下一步。

【约束】
- 每月 API 预算上限 100 元人民币
- 每周最多花 2 小时维护这件事
- 必须能接入豆包/Marvis 这类没有 API 的 AI
- 数据不能出境的部分不能离开本机

【不讨论】
- 不讨论是否要自建模型
- 不讨论 UI 设计

【判断标准】三个月后回看：花出去的钱和时间，换来的决策质量提升是否值得。
```

注意它做了什么：给了可量化的约束（100 元、2 小时），给了会改变答案的判断标准，明确排除了两个最容易跑偏的方向。任务框的作用就是**替模型做减法**。

## 常见毛病

| 毛病 | 后果 | 修法 |
|---|---|---|
| 问题里带暗示（"是不是应该立刻上马？"） | 每个 AI 都顺着你说 | 中性化："是否应该" → "在什么条件下应该" |
| 没有约束 | 回答正确但无法执行 | 写出钱、人、时间 |
| 没有不讨论 | 模型开始发散，答案互相不可比 | 列 2-3 条排除项 |
| 一次问两件事 | 每个 AI 挑一件答，没法互评 | 拆成两个议事会 |
| 没写交付物格式 | 五份答案形状各异，收敛时痛苦 | 一句话写死格式 |
